# Maze Generator & Solver

Генератор и решатель лабиринтов на Java с поддержкой нескольких алгоритмов.

## Содержание

- [Использование](#использование)
- [Требования](#требования)

## Использование

### Генерация лабиринта

**Доступные алгоритмы:**
1. **DFS** (Depth-First Search) - рекурсивный поиск в глубину
2. **Prim True** - классический алгоритм Прима
3. **Cyclic** - генератор неидеальных лабиринтов(с циклами), использующий dfs для генерации идеального алгоритма и создающий в нем циклы

### Решение лабиринта

**Доступные алгоритмы:**
1. **Dijkstra** - гарантирует кратчайший путь
2. **A*** - эвристический поиск с манхеттенской дистанцией
3. **Bidirectional** - использует двусторонний поиск

**Источник лабиринта:**
- Сгенерированный ранее файл

Начало координат в левом верхнем углу, при движении вниз растёт y, вправо - x

## 📖 Детальная документация по использованию

### Команда: `generate`

Генерирует новый лабиринт.

#### Синтаксис

```bash
java -jar app.jar generate [OPTIONS]
```

#### Обязательные параметры

|   Параметр    | Краткая форма |           Описание            |        Значения         |
|---------------|---------------|-------------------------------|-------------------------|
| `--algorithm` | `-a`          | Алгоритм генерации            | `dfs`, `prim`, `cyclic` |
| `--width`     | `-w`          | Ширина лабиринта (без границ) | Целое число > 0         |
| `--height`    | `-h`          | Высота лабиринта (без границ) | Целое число > 0         |

#### Опциональные параметры

|       Параметр        | Краткая форма |                   Описание                   | Значение по умолчанию |
|-----------------------|---------------|----------------------------------------------|-----------------------|
| `--output`            | `-o`          | Файл для сохранения лабиринта                | Вывод в консоль       |
| `--unicode`           | `-u`          | Использовать Unicode символы                 | `false`               |
| `--cycle-chance`      | `-c`          | Вероятность добавления циклов (для cyclic)   | `0.2`                 |
| `--surface-variation` | `-s`          | Вероятность разных поверхностей (для cyclic) | `0.3`                 |

#### Примеры

**Базовая генерация DFS лабиринта**

```bash
java -jar app.jar generate -a dfs -w 10 -h 10
```

**Генерация Prim лабиринта и сохранение в файл**

```bash
java -jar app.jar generate -a prim -w 15 -h 15 -o my_maze.txt
```

**Генерация циклического лабиринта с высокой вариацией**

```bash
java -jar app.jar generate \
  -a cyclic \
  -w 20 \
  -h 20 \
  -c 0.5 \
  -s 0.7 \
  -o complex_maze.txt
```

**Генерация с красивой визуализацией**

```bash
java -jar app.jar generate -a dfs -w 12 -h 12 --unicode
```

### Команда: `solve`

Решает лабиринт и находит путь от начала до конца.

#### Синтаксис

```bash
java -jar app.jar solve [OPTIONS]
```

#### Обязательные параметры

|   Параметр    | Краткая форма |       Описание       |                Формат                |
|---------------|---------------|----------------------|--------------------------------------|
| `--algorithm` | `-a`          | Алгоритм решения     | `astar`, `dijkstra`, `bidirectional` |
| `--file`      | `-f`          | Файл с лабиринтом    | Путь к файлу                         |
| `--start`     | `-s`          | Начальная координата | `x,y` (например, `1,1`)              |
| `--end`       | `-e`          | Конечная координата  | `x,y` (например, `14,14`)            |

#### Опциональные параметры

|  Параметр   | Краткая форма |           Описание           | Значение по умолчанию |
|-------------|---------------|------------------------------|-----------------------|
| `--output`  | `-o`          | Файл для сохранения решения  | Вывод в консоль       |
| `--unicode` | `-u`          | Использовать Unicode символы | `false`               |

#### Примеры

**Базовое решение A***

```bash
java -jar app.jar solve -a astar -f maze.txt -s 1,1 -e 14,14
```

**Решение Dijkstra и сохранение**

```bash
java -jar app.jar solve \
  -a dijkstra \
  -f maze.txt \
  -s 1,1 \
  -e 9,9 \
  -o solution.txt
```

**Решение Bi-Directional с Unicode**

```bash
java -jar app.jar solve \
  -a bidirectional \
  -f maze.txt \
  -s 1,1 \
  -e 14,14 \
  --unicode
```

### Символы поверхностей

| Символ  | ASCII | Unicode | Вес |      Описание      |
|---------|-------|---------|-----|--------------------|
| Проход  | ` `   | `·`     | 10  | Обычный проход     |
| Асфальт | `=`   | `═`     | 5   | Быстрое покрытие   |
| Песок   | `~`   | `≈`     | 15  | Медленное покрытие |
| Болото  | `*`   | `≋`     | 20  | Очень медленное    |
| Стена   | `#`   | `█`     | ∞   | Непроходимо        |

## 📊 Размеры лабиринта

Выходной лабиринт имеет размер **`(width + 2) × (height + 2)`**:
- `width` и `height` - размер внутренней части
- `+2` - границы из стен со всех сторон

## 🗂️ Формат файлов

**На вход подаются только лабиринты, сгенерированные без юникода!**

Лабиринты хранятся в текстовом формате:
- `#` - стена
- ` ` (пробел) - обычный проход
- `=` - асфальт
- `~` - песок
- `*` - болото
- `.` - путь
- `O` - начало пути
- `X` - конец пути

## Требования

### Функциональные

- ✅ Генерация лабиринтов несколькими алгоритмами
- ✅ Решение лабиринтов методами Dijkstra и A*
- ✅ Два режима интерфейса: интерактивный и CLI
- ✅ Отображение пути через лабиринт при его наличии в консоль.
- ✅ Сохранение решения в файл.

### Технические

- Java 11+
- Maven для сборки
- JUnit 5 для тестирования
- SLF4J для логирования
- Picocli для CLI

## Обозначения в лабиринте

```
# — стена
(пробел) — проход
O — начальная точка
X — конечная точка
. — найденный путь решения
```
